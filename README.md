# Number Guesser Game 🎯

A fun, interactive browser-based number guessing game!  
Try to guess the number I’m thinking of between **1 and 99** in **5 tries or less**. 🎉

## Features
- Random number generated between 1 and 99 for each game.
- **Input validation**: cannot guess below 1 or above 99.
- Shows interactive messages for:
  - Too high
  - Too low
  - Correct guess
  - Maximum guesses reached
  - Invalid input
- **Reset button** to start a new game anytime.
- **Fun animations and effects**:
  - Confetti when you guess correctly 🎉
  - Floating numbers in the background for a dynamic feel
  - Interactive buttons and inputs
- Responsive and works on desktop and mobile browsers.

---

## How to Play
1. Open `index.html` in your browser.
2. Enter a number between 1 and 99 in the input box.
3. Click **Submit Guess**.
4. Feedback messages will tell you if your guess is too high, too low, or correct.
5. You have **5 tries** to guess the correct number.
6. If you guess correctly, enjoy **confetti** and a congratulatory message!  
7. Use the **Reset** button to start a new game.
